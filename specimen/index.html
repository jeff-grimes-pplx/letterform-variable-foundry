Apertide — type specimen1

An upright sans drawn from skeletons

A typeface is a set of decisions made once and repeated ten thousand times. Apertide starts from numerical centerlines rather than drawn contours: every stem, bowl and terminal is a stroke along a skeleton whose width, nib and terminal angle are parameters. The nine masters at the corners and midpoints of the weight and width axes are generated from the same recipes, so their points correspond and the variable font interpolates cleanly between them.

The curves are not circles. Round forms lean on unequal corner tension so that the counters open toward the right, and every terminal is cut on one shallow diagonal. Horizontal strokes are lighter than vertical ones, and diagonals are compensated separately so that A, V, W, X and Y hold the same colour as the stems around them. Marks follow the width axis and lighten as the weight grows.

Width is a change of skeleton, not a stretch. The condensed masters move stems closer together and shorten the arches while the stroke stays the same thickness; the extended masters widen the bowls and lengthen the crossbars. Advance widths and sidebearings follow the skeleton so that spacing stays even across the design space, and class kerning is inherited by accented letters.

The identifying forms are the double-storey a, the open-tailed single-storey g, the low-bar A, the folded leg of R, the clipped aperture of e and the squared dots. Apertide is a display and editorial face; text sizes are shown on page 11 for judgement.

Colophon

Metrics

1000 units per em. Cap height 700, x-height 520, ascender 740, descender −210; round overshoot 12 (capitals) and 10 (lowercase). Typographic ascender 940, descender −260, line gap 0 (USE_TYPO_METRICS set); hhea 940 / −260; Windows ascent 1000, descent 400. Underline position −120, thickness 60.

Axes

wght 200 → 800 (default 400), wdth 75 → 125 (default 100). Nine compatible masters at weight 200 / 400 / 800 × width 75 / 100 / 125; the variable font interpolates bilinearly between them. STAT table names seven weights and three widths; Regular is elidable and linked to Bold.

Repertoire

548 glyphs, 477 encoded characters: printable ASCII, Latin-1 Supplement and Latin Extended-A complete; 5 Latin Extended-B and 65 Latin Extended Additional letters (those Welsh, Irish, Maltese, Romanian, Turkish and the other tested languages need, not the full blocks); combining marks with case variants and narrow forms over i and j, typographic punctuation, currency, common mathematical signs, four arrows, f-ligatures, tabular, numerator, denominator, superior and inferior figures, slashed zeros and case-sensitive punctuation. Soft hyphen is intentionally unencoded; Vietnamese stacked accents, the numero sign (U+2116) and the double arrows are out of scope for this build.

Features

GSUB: ccmp, liga (with Turkic exclusions for fi/ffi), tnum, pnum, zero, frac, numr, dnom, sups, subs, ordn, case. GPOS: class kerning, mark attachment. Verified with HarfBuzz 12.3.2 (68 shaping receipts), fontbakery 1.1.0 universal profile (variable font 0 FAIL / 0 WARN; statics 0 FAIL, 12 WARN on one ₩ contour-count statistic), OpenType Sanitizer 9.2.0 and FontForge 20230101.

Version 1.103. Outlines generated programmatically from original numerical skeletons (Python), compiled with fontmake 3.12.2 / ufo2ft 3.9.1 / fontTools 4.67.0; no third-party font outlines were read or traced. Specimen typeset in Apertide through its static instances and variable font, printed from Chromium; glyph map drawn from the same master outlines.

Rendering note

Text set through the static instances is embedded as subsetted TrueType (CID) fonts. Text set through the variable font with font-variation-settings (cover, axis sweeps, design-space matrix) is written by Chromium's PDF backend as Type 3 glyph procedures: exact outlines from the font, searchable through ToUnicode, but not an embedded copy of the font program.
