# A4 acceptance contract

## Thin proof before volume

Draw H O R a e n g and fi from original recipes. Compile compatible weight/width extremes plus the default master into a variable TrueType font. Open it with fontTools and HarfBuzz; shape a ligature and kern pair; render default and corner instances. Inspect round counters, intersections, contrast, sidebearings and motion before expanding the repertoire.

## Twenty-second reveal

0–5 s: the original a skeleton is drawn; its actual compiled outline resolves around it. 5–8 s: alphabet view. 8–12 s: type “Quiet forms, vivid voices.” in the actual tester. 12–20 s: drag weight, then width, with the controls and resulting letterforms visible together. This is a production-app input sequence, not animated replacement UI.

## Release-candidate gates

- Native: variable TTF, static TTFs, WOFF2, compatible source masters, designspace, original generator and pinned dependencies. Every declared codepoint maps to a real glyph. Encoded-character and total-glyph counts reconciled.
- Variation: all nine master coordinates and sampled intermediate locations have valid bounds, positive metrics, noncollapsed counters and compatible topology. Width is not post-hoc outline scaling.
- OpenType: HarfBuzz receipts for kern, liga, tnum, pnum, frac and combining accents. Positive and negative feature tests; language corpus has no .notdef.
- Checks: universal FontBakery or an explicitly defined equivalent with zero unresolved FAILs; preserve raw report, version and command. No silent suppression. Remaining warnings are explained, not renamed as passes.
- PDF: complete alphabet, waterfall, axis sweeps, pangrams, multilingual text, feature comparisons and full glyph map. Actual font embedded. All pages rendered, inspected and repaired. Native parser accepts PDF.
- App: real variable font via @font-face; type/paste/empty/long/unsupported text; all three sliders; feature toggles; every glyph inspectable; drawing animation; downloaded bytes match font/package receipts. No runtime external services.
- QA: local and private hosted URL, pointer and keyboard input. 1440×900, 1280×720, 1280×640, 390×844. Reload, negative inputs, downloads, links, reduced motion, console errors, long-session memory and practical responsiveness.
- Film: exact 60 s and 30 s, 1920×1080 minimum, silent. Genuine app handlers, visible pointer. Frame-stepped capture disclosed with exact i/fps clock, input log and encode settings. All scenes and actual encoded transitions inspected. Retain a clean footage master.
- Rights: original geometry, source URLs/access dates, software versions/licenses, private-review font license. No social publication.
- Challenge: independent specialist review of actual outputs, fixes for substantive findings, then fresh regression. Functional tests do not certify aesthetics. Never claim human type-designer validation.

## Execution sequence

Brief → native proof → original full repertoire → feature/variation validation → specimen and tester → technical and visual repair → private deployment → independent challenge → capture → encoded review → regression → freeze.

Only builds/A4-letterform is writable in the shared repository. Intermediate frames, dependencies and expanded UFO trees stay in workspace scratch; reproducible source and compact packages are preserved. Coordination goes to the commissioned parent at proof, candidate, route-changing blocker and final checkpoints.
